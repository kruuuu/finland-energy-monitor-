# Finland Energy Monitor – Power BI Report

This project is a Power BI report analyzing Finland's electricity usage, with a focus on:
- Overall consumption trends
- Seasonal patterns
- Hourly usage behavior

> Built as part of my learning journey in data analytics, sustainability, and Power BI.

## 📊 Report Pages

### 1. Finland Electricity Usage Overview
- Total electricity consumption (bn kWh)
- Peak hour consumption
- Average daily consumption
- Monthly consumption trend
- Hourly consumption pattern
